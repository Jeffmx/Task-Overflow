# Task OverFlow

Task OverFlow é uma aplicação web de gerenciamento de tarefas e projetos, desenvolvida com React e Vite.

## 🎯 Objetivo

O projeto tem como objetivo colocar em prática conceitos de desenvolvimento Front-End, como componentização, gerenciamento de estado, CRUD, responsividade, consumo de APIs e organização de aplicações React.

## 🛠️ Tecnologias

- React
- Vite
- JavaScript
- React Router
- Styled Components
